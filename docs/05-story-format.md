# Storyspec — the story format

A story is a directory:

```
content/fox-on-the-box/
  story.json          ← the spec (this document)
  audio/p1.mp3 …      ← per-page narration
  audio/p1.words.json ← word timestamps (generated)
  scenes/…            ← frame sequences and/or scene asset files
  cover.webp
```

`story.json` is validated with zod against the types in `src/engine/types.ts`. Everything the reader needs is data; the only code per story is an optional coded-scene module referenced by path.

## Schema by example

```jsonc
{
  "id": "fox-on-the-box",
  "title": "The Fox on the Box",
  "level": 1,                          // display level
  "phonicsScope": {                    // what the reader is assumed to know
    "graphemes": ["s","a","t","p","i","n","m","d","g","o","c","k","e","u","r","h","b","f","l","x","j"],
    "sightWords": ["the", "is", "and"]
  },
  "ambient": "audio/ambient.mp3",
  "sticker": "stickers/fox.webp",
  "pages": [
    {
      "id": "p6",
      "text": "The fox hops on the box!",
      "tokens": [
        { "w": "The",  "sight": true },
        { "w": "fox",  "g": ["f","o","x"] },          // grapheme segmentation
        { "w": "hops", "g": ["h","o","p","s"] },
        { "w": "on",   "g": ["o","n"] },
        { "w": "the",  "sight": true },
        { "w": "box",  "g": ["b","o","x"] }
      ],
      "narration": { "audio": "audio/p6.mp3", "words": "audio/p6.words.json" },
      "scene": {
        "backend": "coded",                            // "coded" | "frames"
        "module": "fox-box",                           // registry key for coded scenes
        "cues": [
          { "atWord": 2, "cue": "jump" },              // fires as t crosses into token 2
          { "atWord": 5, "cue": "land" }
        ]
      }
    },
    {
      "id": "p7",
      "text": "The box tips!",
      "tokens": [ /* … */ ],
      "narration": { "audio": "audio/p7.mp3", "words": "audio/p7.words.json" },
      "scene": {
        "backend": "frames",
        "frames": { "dir": "scenes/p7", "count": 48 }, // scrubbed 0→47 across the page
        "cues": [ { "atWord": 2, "cue": "shake" } ]    // frames backend may map cues to overlays
      }
    }
  ]
}
```

## Rules

- **Graphemes, not letters.** `"ship"` segments as `["sh","i","p"]`. Digraphs/trigraphs/vowel teams are single entries. Segmentation is generated by `scripts/segment.ts` from a curated grapheme–phoneme table, with per-token manual override in the spec winning over the generator.
- **Sight words** (`"sight": true`) are never segmented; the reader highlights them whole and the linter exempts them from scope checking (they must still appear in `phonicsScope.sightWords`).
- **Every token is either segmented or sight** — the linter rejects anything else.
- **Word timestamps** (`p6.words.json`): `[{ "i": 0, "start": 0.32, "end": 0.58 }, …]`, indices into `tokens`. Generated by the narration pipeline; hand-editable.
- **Timeline weighting**: token t-ranges are proportional to narration durations when timestamps exist, else to grapheme counts. Punctuation attaches to the preceding token and gets no range.
- **Cues** reference token indices, not timestamps — authorship stays at the text level, and all modes (finger or clock driven) fire them identically.
- **Text length**: one sentence per page at level 1 (max ~7 words), up to two short sentences at level 2+. The page is a moment, not a paragraph.

## Extension points (reserved, not implemented in POC)

`scene.backend: "rive"`; `page.interactions` for tap targets with rewards; `story.voices` for character-voiced narration; `tokens[].phonemes` for explicit phoneme labels when the grapheme table is ambiguous.

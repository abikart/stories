# Lanternleaf

**Status:** Working

Lanternleaf is the first story world. It is being designed for a progression
from adult-supported first words through approximately second-grade independent
reading, with one shared canon and a primary serialized adventure.

## Current documents

1. [Adventure spine](adventure-spine.md) — the world promise, primary journey,
   path behavior, and episodic story engine.
2. [Path mystery](path-mystery.md) — the current concrete cause-and-effect
   proposal for the fading routes.
3. [Geography and villages](geography-and-villages.md) — terminology, the
   compact four-region world, current map, and settlement concepts.
4. [Village scene references](village-scenes.md) — accepted environment studies
   and the current prompt recipe for each village.
5. [Main characters](main-characters.md) — the current four-character roster
   and the identity and role details still to define.

## Planned foundation

- Reading ladder and editorial constraints
- Character-era sheets
- Master chronology and primary journey outline
- Subplot and early-reader story matrix
- Lanternleaf visual and sound bibles
- Canon ledger

Nothing in this folder is approved canon until its document says so. Working
material may change as the remaining story decisions are made.

# Lanternleaf Master Character Reference Sheet — Reusable Prompt Template

Use the supplied character image as a **rough identity reference** for **[CHARACTER NAME]**.

The reference is a starting point, not necessarily the final style. Preserve the character’s recognizable identity while **adapting the design into the shared Lanternleaf character world**.

The final sheet should define **one canonical character design** that can be reused consistently across many story illustrations.

---

## 1. REFERENCE ADAPTATION RULE

Preserve from the supplied reference:

* species / creature identity
* core silhouette
* major body proportions
* important markings
* primary color relationships
* distinctive anatomical features
* defining personality cues
* essential accessory concept, if one already exists

Modify or simplify anything necessary so the character fits the **Lanternleaf world language** described below.

Do not blindly copy rendering defects, texture, anatomy mistakes, or stylistic inconsistencies from the rough reference.

Priority:

1. **Lanternleaf world identity**
2. **individual character identity**
3. **species recognizability**
4. **accessories and secondary detail**

---

# 2. LANTERNLEAF WORLD CHARACTER LOCK

Every character should look like a different denizen of the **same illustrated world**.

## Shared face language

Use:

* large expressive rounded eyes
* warm dark brown / near-black pupils
* bright, clearly readable eye sparkles
* soft warm highlights inside the eyes where appropriate
* tiny simple nose
* small gentle mouth
* subtle rosy cheeks
* approachable child-friendly facial proportions

The eye treatment should create a recognizable shared family resemblance across Lanternleaf characters without making their faces identical.

### Character-specific facial traits still override the shared style

Preserve individual features such as:

* eyelashes or absence of eyelashes
* eyebrow shape
* muzzle / snout construction
* beak shape
* nose shape
* eye spacing
* facial markings
* cheek placement

Do **not** transfer character-specific facial traits between characters.

---

## Shared shape language

Use:

* rounded silhouettes
* softened anatomy
* compact proportions
* slightly oversized head relative to body
* short, simple, rounded limbs
* clear species-specific features
* gentle organic curves
* minimal sharp geometry

The character should feel:

* cute
* warm
* approachable
* whimsical
* safe
* expressive

Do not distort the species so much that it becomes unrecognizable.

---

## Shared simplification rule

Translate biological complexity into simple storybook forms.

Simplify:

* fur
* feathers
* scales
* shells
* wings
* antennae
* horns
* tails
* paws
* claws
* markings

Keep the defining characteristics, but remove unnecessary realistic complexity.

Details should be **iconic and readable**, not densely rendered.

# 11. WATERCOLOR RENDERING LOCK — CRITICAL

Use **smooth, broad, contiguous watercolor fields with low-frequency tonal variation**.

This requirement applies to **every view and every detail panel**.

Paint major forms using:

* broad transparent washes
* calm continuous color regions
* large unified painted shapes
* gentle large-scale tonal transitions
* subtle wet-on-wet variation only at broad scale

Each body region should feel like **one coherent painted mass**, not a collection of little brush patches.

### Strictly avoid

* mottled watercolor
* patch-by-patch rendering
* repeated tiny brush marks
* noisy pigment texture
* stippling
* granulation simulation
* dry-brush fill texture
* tiny fur strokes inside color regions
* repetitive scale texture
* repeated little tonal islands
* high-frequency value variation

The watercolor should feel:

**smooth, calm, broad, soft, luminous, and continuous.**

---

# 12. LINEWORK LOCK

Overlay the watercolor with expressive **hand-drawn storybook contour lines**.

The lines should feel:

* handmade
* slightly irregular
* gently wobbly
* pressure-sensitive
* mildly chalky / dry-brush
* softly tapered
* occasionally lightly broken

Favor **longer confident contour strokes** around silhouettes.

Use only a few short strokes for:

* fur tips
* tiny anatomy accents
* folds
* wing veins
* shell divisions
* other necessary details

Do not construct soft or furry edges from many repeated tiny marks.

---

## Local-color contour rule

Do **not** use one universal black outline.

Each contour should be a darker related version of the region it surrounds.

Examples:

* reddish-orange contour around orange fur
* warm beige / ochre around cream areas
* deep honey-ochre around yellow
* warm brown around dark brown markings
* deeper green around green body areas
* muted lavender-brown around translucent wings
* warm brown around wood and leather

Facial features such as pupils may naturally be very dark.

Avoid:

* black silhouette outlines everywhere
* perfectly smooth digital curves
* uniform line thickness
* vector-clean contouring
* mechanically closed paths
* sticker-like line art
* excessive sketch-search lines

The contour should feel **drawn over watercolor by hand**, not digitally traced.
